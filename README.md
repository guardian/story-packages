### Dev container (recommended)

The quickest way to get started is to use the [dev container](https://containers.dev/)
committed to this repository. It provides an isolated, reproducible environment with all
of the required tooling (Java, Node.js, sbt, the AWS CLI, Grunt and JSPM) already pinned
and installed. The configuration is generated by the Guardian's
[devenv](https://github.com/guardian/devenv) tool and lives in [.devcontainer](.devcontainer).

#### Prerequisites (on your host machine)

- [Docker](https://www.docker.com/)
- An IDE with dev container support, such as
  [VS Code](https://code.visualstudio.com/docs/devcontainers/containers) (with the Dev
  Containers extension) or IntelliJ IDEA.
- [mise](https://mise.jdx.dev/), used to install the pinned `devenv` tool.
- [dev-nginx](https://github.com/guardian/dev-nginx)

#### 1. Set up dev-nginx on your host

From the repository root, install the pinned tooling and generate the personal dev
container definition:

```bash
dev-nginx setup-app ./nginx/mapping.yml
```

#### 2. Reopen the repository in the container

Open the repository in your IDE and reopen it in the dev container (in VS Code:
*Dev Containers: Reopen in Container*). On first creation the container installs the
pinned tools via `mise`, installs `grunt-cli` and `jspm`, and configures the JSPM GitHub
registry. 

The container sets `DEVCONTAINER=true` and forwards port `9000` to your host. `nginx` is
*not* configured inside the container - it should have been set up on the host in the step 1.
The app is reached directly on [https://packages.local.dev-gutools.co.uk](https://packages.local.dev-gutools.co.uk).

#### 3. Provide AWS credentials and run the app

[`./setup.sh`](setup.sh) downloads local config from S3 and therefore needs a working
`cmsFronts` AWS profile available inside the container. Load the credential "CMS Fronts - Run Story Packages locall"
from Janus. Once that profile is available,
follow [Run the App](#run-the-app) from inside the container.


### Manual setup

If you prefer to develop directly on your host machine instead of the
[dev container](#dev-container-recommended), install each of the dependencies below.

#### Application dependencies

Install each of the things listed:

#### Git

Mac:
```bash
brew install git
echo 'export PATH="/usr/local/bin:$PATH"' >> ~/.bash_profile
```

#### [Homebrew](http://brew.sh/)

This is needed on Mac only:
```bash
ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"
```

#### JDK

See [.tool-versions](.tool-versions)

Ubuntu:
```bash
sudo apt-get install openjdk-8-jdk
```

Mac: Use `sdkman` or install from [Oracle web site](http://www.oracle.com/technetwork/java/javase/downloads/jdk8-downloads-2133151.html)

#### Node.JS

Ubuntu:
```bash
sudo apt-get install nodejs
sudo apt-get install npm
sudo ln -s /usr/bin/nodejs /usr/bin/node
```

Mac:
```bash
brew install node
```

#### Grunt (build tool)

Ubuntu/Mac:
```bash
sudo npm -g install grunt-cli
```

#### JSPM (package management)

Ubuntu/Mac:
```bash
npm -g install jspm@0.16.55
jspm registry config github
```

It'll ask for a GitHub access token. Go to GitHub Settings -> Applications and [generate new token](https://github.com/settings/tokens/new). Ensure only the public_repo scope is checked.

#### nginx

Mac:
```bash
brew install nginx
```

[dev-nginx](https://github.com/guardian/dev-nginx)

#### sbt

Mac:
```bash
brew install sbt
```

#### aws cli
```bash
pip install awscli
```


### Run the App

You will need the following credentials:
- cmsFronts - Run Story Packages locally

#### 1. Run the setup script
```bash
./setup.sh
```
This will fetch the required config files, install the Javascript dependencies, and (on the
manual host setup) configure the nginx mappings. Inside the dev container the nginx step is
skipped and the Chromium system libraries needed by the tests are installed instead.

#### 2. Run the application
```bash
./scripts/start.sh
```


Now check that you are up and running by hitting the following URL.
[https://packages.local.dev-gutools.co.uk](https://packages.local.dev-gutools.co.uk)


### Unit tests

Unit tests run with `grunt`, `karma` and `jasmine`.

```bash
grunt test
```
Runs the tests once in headless Chromium and exits with an error if tests fail.

```bash
grunt test --no-single-run
```
Starts `karma` in debug mode, you can connect your browser at [http://localhost:9876?debug.html](http://localhost:9876?debug.html)

You can run a single test going to [http://localhost:9876/debug.html?test=collections](http://localhost:9876/debug.html?test=collections), spec files are inside `public/test/spec`.

You need to have version node version 4.1 or higher installed to be able to run the tests.

Enjoy!
